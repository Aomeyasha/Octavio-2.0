📖 BITÁCORA: PRINCIPIOS DE CONTEO

1. Correspondencia Uno a Uno ☝️

A cada elemento del conjunto se le asigna una y solo una etiqueta numérica ("uno", "dos", "tres"). No se salta ninguno ni se repite.

2. Orden Estable 🔢

Las palabras numéricas deben recitarse siempre en el mismo orden repetible (1, 2, 3, 4, 5...). No se pueden cambiar los nombres de secuencia.

3. Cardinalidad 🔮

El último número dicho al contar una colección indica la cantidad total de elementos que contiene el conjunto completo.
